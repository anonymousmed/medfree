## Architecture decisions locked in for this project

- **Monorepo** (workspaces) — one repo, clean deploys to Vercel + Render/Railway.
- **Next.js + TypeScript + Tailwind** frontend; **FastAPI + SQLAlchemy async + Alembic** backend.
- **Provider-agnostic abstractions** for DB, storage, auth, hosting (swappable later).
- **RBAC enforced at backend** — hiding a UI button is never a security control.
- **Human Atlas = centerpiece**; books = knowledge/reference layer.
