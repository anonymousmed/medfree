# MEDFREE — Content Sourcing

Classify every source and never let a low-quality blog be the sole basis for important clinical information.

## Source types
- **A.** Primary evidence
- **B.** Clinical guidelines
- **C.** Academic references
- **D.** Open textbooks
- **E.** Educational resources
- **F.** Original platform content
- **G.** Community content (reviewed; never auto-published)

## Prioritized sources
| Source | URL | Use |
|---|---|---|
| OpenStax | https://openstax.org/ | Open textbooks where license permits |
| NCBI Bookshelf | https://www.ncbi.nlm.nih.gov/books/ | Biomedical reference (not all copyable) |
| PubMed | https://pubmed.ncbi.nlm.nih.gov/ | Research discovery & evidence |
| PubMed Central | https://pmc.ncbi.nlm.nih.gov/ | Full-text OA with reuse licenses |
| Europe PMC | https://europepmc.org/ | OA literature discovery |
| WHO | https://www.who.int/ | Public-health resources (check rights) |
| ICMR | https://www.icmr.gov.in/ | Indian research, ethics, AI guidance |
| Wikimedia Commons | https://commons.wikimedia.org/ | Open images (verify each file) |
| DOAJ | https://doaj.org/ | Legitimate OA journals |
| PhysioNet | https://physionet.org/ | Biomedical datasets |
| BodyParts3D / Anatomography | https://github.com/Kevin-Mattheus-Moerman/BodyParts3D | Open 3D anatomy (CC BY-SA 2.1 JP) |
| Radiopaedia | https://radiopaedia.org/ | Reference/case learning unless licensed |

## Workflow
Every content item follows:
`research → draft → reference check → medical review → educational review → rights check → publish → periodic review`.

**AI may assist; AI does not replace medical review.**

## Community content
`submit → automated checks → moderation → rights check → medical review → quality review → approval → publish`. **Never auto-publish user-submitted medical content.**
